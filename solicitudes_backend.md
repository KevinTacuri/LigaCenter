# Registro de Solicitudes para el Equipo de Backend

Este archivo sirve como canal de comunicación y registro oficial de los cambios, ajustes o nuevos endpoints que el equipo de **Frontend** necesita solicitar al equipo de **Backend**.

---

## 📋 Guía para Registrar una Nueva Solicitud

Al solicitar un cambio, por favor estructúralo de la siguiente manera para facilitar el trabajo de los compañeros de backend:

1. **Título de la Solicitud:** Corto y descriptivo (ej. *Endpoint para listado de equipos*).
2. **Prioridad:** (Baja / Media / Alta / Crítica).
3. **Descripción:** Qué datos se necesitan mostrar en el frontend y por qué.
4. **Estructura Esperada:**
   - **Ruta:** (ej. `GET /api/equipos`).
   - **Parámetros requeridos / Query params:** (ej. `page`, `disciplina_id`).
   - **Formato del JSON de respuesta esperado:**
5. **Estado:** (Pendiente / En Proceso / Completado).
